# Killer Integrated Demo Workflows

These prompts demonstrate the power of combining multiple ambitious Remirdy features.

## Demo 1: Real World + Weather + Multi-Agent Polish + 3D Print Ready

```
1. create_and_polish_real_world_terrain("Kapadokya, Türkiye", radius_km=2.2, max_polish_iterations=3)

2. set_real_time_weather("Nevşehir", time_of_day="sunset", intensity=1.3)

3. orchestrate_scene_with_agents(
    "dramatic golden hour fairy chimneys with warm cinematic lighting and natural materials",
    focus_areas=["lighting", "materials", "composition", "critique"],
    max_iterations=2
)

4. prepare_for_3d_printing(min_thickness_mm=2.0)
```

Expected feeling: You get a real geographical location, lit according to actual weather, beautifully polished by specialist AI agents, and ready for physical 3D printing.

## Demo 2: Video Reference → Intelligent Reconstruction

```
1. create_scene_from_video_reference(
    "/path/to/breaking_bad_lab_footage.mp4",
    num_keyframes=4,
    auto_polish_with_agents=True
)
```

The system creates references, blockout, then runs the full multi-agent team to turn a vague video reference into a production-usable cinematic scene.

## Demo 3: Prompt → City at Night → Weather → Agents → Export

```
1. create_procedural_city_blockout(
    "neo-Tokyo cyberpunk night, dense, 1.8 km²",
    size_km=1.8,
    style="cyberpunk"
)

2. set_real_time_weather("Tokyo", time_of_day="night")

3. orchestrate_scene_with_agents(
    prompt="intense neon cyberpunk city at night with rain reflections",
    focus_areas=["materials", "lighting", "composition", "critique"],
    max_iterations=3
)

4. (Future) export_full_unity_project()
```

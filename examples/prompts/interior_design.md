# Interior design prompts

### Luxury living room
```
Create a modern luxury living room interior with sofa, coffee table, TV wall,
large windows, warm lighting, wood floor, marble wall detail, plants, and a
professional architectural render camera.
```

### Minimalist bedroom
```
Create a minimalist bedroom with a bed, nightstands, wardrobe, a window and soft
natural lighting, portfolio-quality render.
```

### Modern office
```
Create a modern office interior with six desks, chairs, glass partitions,
ceiling light panels and an architectural camera.
```

### Manual build
```
create_living_room_scene(style="luxury_apartment", warm_lighting=true)
apply_interior_material_palette(palette="warm_modern")
setup_archviz_camera(focal_length=28)
render_final(filename="livingroom.png")
```
